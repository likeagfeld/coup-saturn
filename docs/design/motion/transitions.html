Transitions

All whole-screen transitions run on VDP2 colour offset, which applies a signed R/G/B offset after colour calculation to every enabled screen at once — background, sprites and text together, with no VDP1 command cost. This is the only mechanism that can fade the text layer, since the 4bpp font is colour-bank data that VDP1 blending cannot touch.

Same register, positive offset: 2 frames up, 10 frames decay. Used on challenge/block resolution and the coup action. Costs nothing in fill rate, so it is safe to fire during the busiest frames.

Honest limitation: mesh (CMDPMOD bit 8) is a fixed 50% checkerboard, not a variable dissolve — it cannot ramp coverage. The dissolve reads as "stipple on, then darken": mesh engages in one frame, and the colour-offset ramp carries the rest. Its virtue is that it costs nothing and works on every colour mode including the colour-bank font, which is why it is the fallback wherever blending is unavailable.
