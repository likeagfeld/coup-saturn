Card Flip — 12-Frame Storyboard

One distorted sprite command per frame (Comm=0010, four free vertices). The quad collapses toward its centre line, the texture swaps at the edge-on midpoint, then it expands as the opposite face. 12 frames = 200 ms at 60 fps. Card is the existing 48×72 CARD_BACK / portrait art — no new textures.

Vertex assignment (centre cx, top y, card height H=72). 0-90°, right edge receding:
xa=cx−hw, ya=y · xb=cx+hw, yb=y+dy · xc=cx+hw, yc=y+H−dy · xd=cx−hw, yd=y+H
90-180°, left edge receding: mirror dy to the A/D pair. hw = (W/2)·|cos θ|, dy = (H·0.12)·|sin θ|.

Rules honoured: hw clamps to ≥1 so the quad never fully degenerates (coincident vertices are legal — triangle or line — but 1 px keeps the sprite addressable); HSS (CMDPMOD bit 12) may be set on frames 4-8 where reduction is heavy, and is safe here because end codes are already disabled; the card's own gouraud table can ride the same command so the receding edge darkens as it turns. Requires the sprite to be in LUT/RGB colour mode (spec §4.6 item 7) — a colour-bank card cannot be shaded.

Gate G6 asserts quad width ≤2 px at the midpoint frame and full art restored at the final frame; G9 asserts the flip actually changes pixels versus a flip-disabled capture.
