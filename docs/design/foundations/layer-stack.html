VRAM bank plan: A0 = scene bitmap (128 KB exactly) · A1 = line-scroll / back-gradient / line-color tables (≤4 KB, below SGL's reserved top 256 B) · B0 = reserved for future overlay plane · B1 = text cells + PNT (untouched).
