Panel & Effect Styles

Every style maps to one concrete VDP1 mechanism with a measured cost class. Gradient panels replace today's flat rectangles at identical fill cost (gouraud is a write-only mode — ST-013-R3). The 6× effects (shadow, glow) are budgeted per frame and gated by the BEF transfer-over check.

CURRENT
Flat panel (today)Polygon, RGB555, grda=0. What every screen uses now. baseline
FACELIFT
Gouraud panel + gold borderPolygon + 8-byte gouraud table (4-corner gradient); Polyline + gouraud for the brass→bronze frame. write-only — same cost as flat
CARD
Drop shadowShadow-mode polygon (ccalc=001) offset +8,+8 behind panels/cards. Halves luminance of RGB pixels beneath. 6× fill on covered px — card-sized only
YOUR TURN
Selection glowHalf-transparent RGB polygon ring (ccalc=011) around the active seat / focused button. 6× fill — ≤8k px per frame
ELIMINATED
Dimmed stateHalf-luminance (ccalc=010) redraw of the same sprite — no second texture, no framebuffer read. cheap
DISSOLVE
Mesh dissolveCMDPMOD bit 8 checkerboard. Works on everything including palette text — the free transparency. free
Gradient timer barGouraud polygon, table animated green→amber→red as the response window drains. +8 B/frame table write (double-buffered pool)

Hard rule (G5): no shadow/glow surface may cover text — the 4bpp font is color-bank code (MSB=0), so blends would replace glyphs, not shade them. Text fades use VDP2 color offset or mesh instead.
