# Sound effects — the full list, and the budget it has to fit in

Recorded 2026-08-06 from the user's notes.

**Custom SFX are being produced by one of the team's own devs.** Everything
placed by this plan is a PLACEHOLDER and must be replaceable one-for-one when
the real audio lands — that requirement shapes the design below more than
anything else, so the swap is a data change and never a code change.

## The measured constraint, before any sourcing work

| | bytes |
|---|---|
| Sound RAM | 524,288 (512 KB) |
| `SFX_BASE_OFFSET` (`coup_audio.c:64`) | 442,368 (`0x6C000`) |
| **Available to SFX** | **81,920** |
| Used by the current 8 effects | 77,098 (94%) |
| **Free** | **4,822** |

At the current average of 9.6 KB per effect, that is room for **half of one
more sound.**

The requested list expands to roughly **60 effects** — the eight "each
character" categories are 8 x 5 = 40 on their own. At the present encoding
that needs ~570 KB into an 82 KB hole. **The list as written cannot be
sampled one-file-per-sound. This is not a sourcing problem and no amount of
searching for smaller files solves it.**

## What actually makes it fit

Four levers, in order of how much they buy and how little they cost:

1. **Pitch-shift the per-character variants instead of sampling them.** The
   SCSP already does this in hardware for free — `coup_audio.c:111` computes
   OCT/FNS to retune 44100 Hz data to 11025 Hz, so the mechanism is present
   and proven. Five characters sharing one sample at five pitches turns 40
   sounds into **8**, and gives each character a consistent voice, which is
   better design than five unrelated clips. This is the single biggest win.
2. **Drop the sample rate for short UI blips.** A d-pad tick carries no
   content above ~4 kHz. 11025 -> 5512 Hz halves those files with no audible
   loss on the ones that are pure transient.
3. **Trim hard.** The current set averages 9.6 KB ~ 0.44 s at 11025 Hz. Menu
   clicks should be 40-80 ms, not 440.
4. **Reclaim `SFX_BASE_OFFSET` only if the first three are not enough**, and
   only after proving what occupies `0x00000-0x6C000` — that region is the
   sound driver's, and taking it back is a real risk, not a free win.

Target after 1-3: ~24 distinct samples, most of them short. That fits.

## Licensing — non-negotiable

This repo is public. The existing set is already CC0 and says so at the top of
`coup_sfx_data.h` (Kenney.nl, OpenGameArt, Cockatrice). Anything added must be
**CC0 or public domain only** — not "free to use", not "free with
attribution", not "royalty free", all of which carry terms CC0 does not.

Every file must have its source URL and licence recorded in the generated
header, per sample, so provenance survives after the placeholders are
replaced. A sample whose licence cannot be established does not go in.

## How the swap has to work

The dev's custom audio replaces the placeholder WAVs and the generator is
re-run. Nothing in `coup_audio.c`, no enum, no call site changes. If replacing
a sound requires touching C, the design is wrong.
