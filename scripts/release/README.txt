Coup for Sega Saturn - @VERSION@
================================

Burn game.cue to a CD-R, or load it in a Saturn ODE / emulator.

FILES
  game.cue        the cue sheet - load THIS, not the bin
  track01.bin     data track (game)
  rebellion.wav   CD-DA audio track (music)

All three must sit in the same folder. The cue references the other two by
name; moving or renaming either will break the disc.

ONLINE PLAY
  Saturn: NetLink modem via DreamPi.
  Browser / mobile cross-play against Saturn players:
      https://saturncoup.duckdns.org

2-6 players. Bots fill any empty seats.
